# Ecrit — OpenSpec Feature Tracking

This directory tracks all features, milestones, and the development roadmap for Ecrit.

## Structure

- `roadmap.yaml` — milestones and release plan
- `status.yaml` — current implementation status of all features

## Milestones

1. **v0.1 — Foundation**: Rust core, design system, Dashboard, basic Manuscript editor
2. **v0.2 — Full Editor**: All 5 phases (Plan, Outline, Manuscript, Proofread, Deliver)
3. **v0.3 — Project Management**: New project wizard, import, settings, format system
4. **v0.4 — Polish**: Overlays, keyboard shortcuts, theme toggle, sprint timer, command palette
5. **v0.5 — Export & Sync**: PDF/ODT export, git snapshots, remote sync, cloud export
6. **v1.0 — Release**: Series projects, modules, production reports, scene numbers, revisions
7. **v1.5 — Platform**: Localization, plugin marketplace, Android companion, real-time collaboration, FDX import
8. **v2.0 — Craft Tools**: Bookmarks, scene tags, autosave, EPUB export, orphan finder, annotations, analytics, spell check, title templates, character cards
