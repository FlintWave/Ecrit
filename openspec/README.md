# Écrit — OpenSpec Feature Tracking

This directory tracks all features, milestones, and the development roadmap for Écrit.

## Structure

- `roadmap.yaml` — milestones and release plan
- `features/` — individual feature specs organized by area
- `status.yaml` — current implementation status

## Milestones

1. **v0.1 — Foundation**: Rust core, design system, Dashboard, basic Manuscript editor
2. **v0.2 — Full Editor**: All 5 phases (Plan, Outline, Manuscript, Proofread, Deliver)
3. **v0.3 — Project Management**: New project wizard, import, settings, file management
4. **v0.4 — Polish**: Overlays, keyboard shortcuts, theme toggle, sprint timer
5. **v0.5 — Export & Sync**: PDF/ODT export, git snapshots, remote sync
6. **v1.0 — Release**: Android companion, series projects, modules, production reports
